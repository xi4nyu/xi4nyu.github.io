### 介绍
GLM-4.6 是智谱推出的最新旗舰模型，总参数量：355B，激活参数：32B，在基准测试中编码能力已经对齐Claude Sonnet 4，是已知的国内最好的Coding模型。
上下文窗口已经从128K扩展到了200K，推理，搜索，写作，多语言翻译均有提升：支持深度思考，流式输出等多种能力。适用于AI Coding和智慧办公等多场景。


### 模型信息

| 类别 | 具体内容 |
| ---- | ---- |
| 参数量 | 总参数量 355B，激活参数 32B |
| 输入模态 | 文本 |
| 输出模态 | 文本 |
| 上下文窗口 | 200K（较 GLM-4.5 的 128K 大幅扩展） |
| 最大输出 | Tokens	128K |


### AI Coding 测试

我们使用官方推荐的 [opencode](https://opencode.ai/) 进行测试编码能力。

1. 安装 opencode:

```bash
curl -fsSL https://opencode.ai/install | bash
```

2. 设置API-KEY

```bash
opencode auth login
```
* 添加 API-KEY

3. 运行 opencode
```bash
opencode

# 使用/models 列出模型，选择 GLM-4.6
```

4. 输入需求，生成代码
